# Keyboard Shortcuts

ExoDeck is designed for speed and efficiency, offering comprehensive keyboard navigation.

## Global Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **`/`** | Open the global navigation overlay (search/filter pages and items) |
| **`.`** | Open / toggle the floating navigator overlay |
| **`#`** | Open the workspace selection overlay |
| **`s`** | Open / close the document outline sidebar (on Note pages) |
| **`e`** | Edit the current page |
| **`Ctrl` + `s`** / **`Cmd` + `s`** | Save changes (when in edit mode) |
| **`+`** | Open the "Add ..." picker to add a new page or item |
| **`g`** | Create a new Grid page |
| **`o`** | Toggle the document outline sidebar (on Note pages) |
| **`O`** (`Shift` + `o`) | Open the headings search overlay (on Note pages) |
| **`x`** | Collapse / expand all sections in the sidebar or outline |
| **`q`** | Create a new Note page |
| **`w`** | Create a new Whiteboard page |
| **`b`** | Create a new Business Process page |
| **`p`** | Print the current Note, Whiteboard, or Business Process page |
| **`n`** | Open / toggle the notifications dropdown |
| **`t`** | Open / toggle the tasks panel (all workspaces) |
| **`Esc`** | Close modal dialogs, floating navigator, search overlay, or cancel edit mode |

## Floating Navigator

| Shortcut | Action |
| :--- | :--- |
| **`.`** | Open / close the floating navigator overlay |
| **`#`** | Open workspace selector |
| **`ArrowDown`** / **`ArrowUp`** | Move selection between visible pages, groups, and workspace switcher |
| **`ArrowRight`** / **`ArrowLeft`** | Switch to the next / previous workspace |
| **`Home`** (`Pos 1`) | Focus workspace switcher (or first workspace in switcher) |
| **`End`** | Jump to last visible page/item in the navigator |
| **`Enter`** | Open selected page or toggle group / confirm workspace |
| **`Ctrl` + `Enter`** / **`Cmd` + `Enter`** | Open selected page in a new browser tab |
| **`x`** | Collapse / expand all sections |
| **`Esc`** | Close floating navigator |

## Document Outline (Sidebar)

| Shortcut | Action |
| :--- | :--- |
| **`o`** | Focus document outline (or open/close on Note pages) |
| **`s`** | Open / close document outline sidebar (on Note pages) |
| **`ArrowDown`** / **`ArrowUp`** | Move selection between visible headings and sections |
| **`ArrowRight`** | Expand section branch / navigate into sub-headings |
| **`ArrowLeft`** | Collapse section branch / navigate to parent section |
| **`Home`** / **`End`** | Jump to first or last visible heading |
| **`Enter`** | Jump to selected heading and focus document content |
| **`Space`** | Preview selected heading (keep focus in outline) |
| **`x`** | Collapse / expand all sections |
| **`Esc`** | Exit outline focus and return to document content |

## Global Navigation Overlay

| Shortcut | Action |
| :--- | :--- |
| **`ArrowDown`** | Move selection down |
| **`ArrowUp`** | Move selection up |
| **`Enter`** | Open selected result |
| **`Esc`** | Close overlay |

## Edit Mode Shortcuts

| Shortcut | Action |
| :--- | :--- |
| **`Enter`** | Save changes when editing group titles or page titles |
| **`Esc`** | Cancel editing and revert to the original content |

## General Navigation

| Shortcut | Action |
| :--- | :--- |
| **`Tab`** | Navigate through links and buttons sequentially |
| **`Shift` + `Tab`** | Navigate backward through focusable elements |
| **Right-Click** | Open browser context menu to open page/link in new tab |
| **Middle-Click** / **`Ctrl` + Click** | Open page or link in a new browser tab |
